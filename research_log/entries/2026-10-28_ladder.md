**S1 → build S2: GO** (n_A = 5, N_B = 80). grid_pseudo closes 94.8% (d = 1) / 88.3% (d = 2) of the A-only → oracle gap
(grid_exact 95.3% / 90.1%); unimodal posteriors 98% / 97%. Pseudo vs exact chain rule: ≤ 0.04 nats/query apart at

**Descriptive.**
- One hypothesis is not enough at small n_A: unimodal 56% / 84% (d = 1, n_A = 1 / 2), 72% / 78% (d = 2).
- The likelihood landscape over s is rugged: GD (Adam, 200 steps) from s = 0 reaches the grid MAP's log-likelihood in
  45–55% (d = 1) / 43–61% (d = 2) of shift pairs; best of 8 starts in 89–99%.
- d = 2: s is only partly identifiable (median MAP error 0.050 at n_A = 5, 0.033 at 10; mass within 0.05 of s 0.51 /
  0.58) while predictions close 88%: ridges along flat directions of f. Supervise in function space, not ‖s − s_true‖²
  alone.
- Unrelated stratum: grid_pseudo / grid_exact cost +5.1 to +13.2 nats/query vs A-only; with the null hypothesis
  (bayes_null) +0.38 at n_A = 1, ≤ 0.03 from n_A = 5.
- N_B = 200 probe (outside pfn_large's n ≤ 100): oracle −4.35 vs −4.24 (d = 1), −3.82 vs −3.47 (d = 2); no breakdown.

**Interpretation.** The location signal is there and the frozen PFN's query path delivers it exactly; a Bayes learner
over shifts realizes most of it from 2–5 A points. The obstacle for an amortised model is search, not likelihood:
proposals / several starts matter more than local refinement, and K > 1 is needed at n_A ≤ 2.
