## §1 Design, sanity and sampler (2026-10-23, 08:40)

- **Why.** The output-map-only stratum isolates identifying a relation with x shared (no warp), with an exact
  frozen-PFN reference (noise is added before the ECDF, so g⁻¹(y_A) is a prior observation). The user asked for it
  2026-10-22; the decision rule in notebook 03 was drafted by Claude and not edited by the user before the run.
- **Sanity** (`results/outmap/sanity_20261023-083233`, commit 3d681cb; d = 1, identity, 2 pairs): `oracle_g` =
  `naive` exactly (true g = id); `bayes` reaches the oracle by n_A = 8 (−3.218 vs −3.218); P(identity) = 0.96 after
  one A point; n_A = 0 gives the prior masses exactly. Same at the previous commit (`sanity_20261023-075927`).
- **Sampler.** Scratch checks on 3 outmap pairs (d = 1, not reported): a fixed 16 × 16 or 32 × 32 quantile grid of
  the g prior collapses (ESS 1–3 at n_A ≥ 2, MC error 0.02–0.05); one-shot local proposals are worse (MC up to
  1.2 nats). Adaptive multiple importance sampling (16 × 16 grid, 4 rounds × 24 draws per n_A) gives MC error
  0.046 / 0.045 / 0.026 / 0.010 / 0.006 at n_A = 0 / 1 / 2 / 4 / 8, ESS 47–285. Ignoring g is catastrophic:
  `naive` is +14.6 nats per query at n_A = 0 on those pairs.
- **Cost.** ≈ 60 s per pair-evaluation at d = 1 on the laptop CPU (16 threads), ≈ 3× at d = 2. Pilot: d = 1 on the
  laptop (`runs/outmap/pilot_20261023-083513`, ≈ 3 h); d = 2 on ulysses (GPU) from midnight when idle.

## §2 Pilot (2026-10-23, 11:30)

- **What ran.** 6 members, 50 pairs each, all DONE: d = 1 `results/outmap/pilot_20261023-083513` (3d681cb, laptop),
  d = 2 `results/outmap/pilot_20261023-100509` (67d09dd, ulysses GPU). The commits differ only in the device option.
- **Result (notebook 03, Observations).** On outmap pairs gain_bayes = 2.23 / 1.90 / 1.16 nats (d = 1) and
  1.99 / 1.49 / 0.97 (d = 2) at n_A = 2d / 4d / 8d, CI lower bounds ≥ 1.0. G = 0.72 / 0.84 / 0.88 and 0.83 / 0.87 /
  0.95. In-context prior at n_A = 0: 1.20 (d = 1), 0.60 (d = 2). Naive pooling: −3.7 to −9.2. Identity sanity:
  G = 1.00 at 8d. Unrelated pairs: −0.79 (d = 1) and −0.26 (d = 2) at n_A = d, ≈ 0 from 2d.
- **Verdict by the rule: IMPRECISE.** The MC error is 0.03–0.07 in 5 of 6 gate cells (limit 0.025); safety fails at
  n_A = d. If precise, the numbers would be PARTIAL (G = 0.72 < 0.75 at d = 1, n_A = 2), IDENTIFIED-level elsewhere.
- **Interpretation.** An output relation of 2 parameters is mostly identified by n_A = 4d, so B is worth 1–2 nats per
  query. Not registering it is catastrophic, which matters for any pooling architecture. The negative transfer at
  one point per dimension on unrelated pairs is the Bayes learner's own price, not a sampler artefact (P(related)
  ≈ 0.5 at n_A = d), so the drafted safety threshold was too strict for n_A = d.
- **Next.** The pre-registered consequence: a finer sampler on the gate cells only (outmap × d ∈ {1, 2}), with
  k_prior = 1024 and k_local = 48, on ulysses before 16:00 (pilot stage, same rule).
